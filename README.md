# Преамбула
Данный репозиторий создан в рамках обучающего курса от института Вега "Программная инженерия и C++ для количественного анализа и алгоритмической торговли". В качестве темы проекта я выбрал фреймворк для бектестирования торговых стратегий. 

Выбор обусловлен одновременно простотой и нетривиальностиью решаемого вопроса. С одной стороны, разработка "ядра" бестеста занимает как правило не более 10% времени разработки. С другой стороны, ввиду большого разнообразия возможных торговых стратегий, создание некого единого фреймворка может быть нетривиальным. Подход к проверке альфы может ограничиться простым перемножением матриц, программирование и исполнение которым занимает минимум времени. Однако, симуляция исполнения заявок наоборот - требует значимо больших компутационных затрат и совершенно иного подхода к реализации стратегии. Данный репозиторий призван предоставить гибкость в гранулярности бэктеста и других важных областей тестирования.

По условиям курса, тема должна быть согласована с преподавателем. Однако, ввиду моего позднего присоединения к группе, решил проявить инициативу и сделать основу проекта минуя данный этап. Если тема оказывается неприемлимой, прошу сообщить об этом и будет выбрана другая тема.
